# Installing Docker on Raspberry Pi

The main instructions are available on [docker.com](https://docs.docker.com/engine/install/debian/), I'm using [Raspbian Trixie](https://www.raspberrypi.com/news/trixie-the-new-version-of-raspberry-pi-os/).

I followed the [Install using the `apt` repository](https://docs.docker.com/engine/install/debian/#install-using-the-repository) method of installation.
